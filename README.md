# RevisionCore - Complete Version

Modern revision website with flashcard import, working streak system, and PDF annotation.

## Quick Start
1. Install Flask: `pip install flask`
2. Run: `python app.py`  
3. Open: `http://127.0.0.1:5000`

## New Features
✅ **Import Flashcards** - Paste Quizlet-style text with custom separators
✅ **Working Streak** - Tracks daily study activity
✅ **Preview Cards** - See all cards before saving
✅ **Save to Subjects** - Import directly into Biology, Chemistry, Physics, or Maths

## How to Import Flashcards
1. Click "Import Cards" button
2. Select subject
3. Paste your flashcards (format: Term, Definition)
4. Choose separators (comma, semicolon, tab, pipe, etc.)
5. Click "Preview Cards"
6. Review and click "Save All Cards"

Built with Flask, HTML, CSS, JavaScript - 100% local and free!
